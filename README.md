# 🌍 CommunityLens

### A Community Feedback and AI-Powered Issue Prioritization Platform

CommunityLens is a web application that helps communities submit feedback about local problems and enables administrators to review, organize, and prioritize reported issues.

## ✨ Features

- 👤 User registration and login
- 📝 Submit community feedback
- 📍 Select the problem location on a map
- 🚦 Specify the urgency of reported issues
- 🛠️ Admin dashboard to review and update issue status
- 🤖 AI-assisted grouping of similar feedback
- 📊 Prioritize issues based on reported feedback

## 🧰 Technologies Used

- Python
- Flask
- SQLite
- HTML and CSS
- JavaScript
- Scikit-learn
- Leaflet maps

## 🚀 How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Install the required Python packages:

   ```bash
   pip install flask flask-login scikit-learn
   ```

5. Run the application:

   ```bash
   python app.py
   ```

6. Open your browser and visit:

   http://127.0.0.1:5000

## 🎯 Purpose

CommunityLens aims to make community feedback easier to collect, understand, and prioritize, helping administrators identify issues that need attention.
